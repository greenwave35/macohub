강의자료 허브

수강 중인 과정을 선택하고 안내받은 비밀번호를 입력하세요.

01

Python 기본과정

MACO 1

출력·입력·변수부터 자료형, 연산자, 조건문과 반복문까지 학습합니다.

02

Python 심화과정

MACO 2

모듈, 함수, 클래스, 파일 입출력과 예외처리를 학습합니다.

03

데이터분석 기초과정

MACO 3

데이터의 구조를 이해하고 수집·정리·시각화의 기본 과정을 학습합니다.

04

데이터분석 심화과정

MACO 4

실제 데이터를 결합·분석하고 프로젝트 결과를 시각화하는 방법을 학습합니다.

05

인공지능 활용 데이터분석과정

MACO 5

생성형 인공지능을 활용해 데이터를 탐색·분석하고 결과를 효과적으로 해석합니다.

06

파이썬 활용 업무자동화 과정

MACO 6

반복 업무를 파이썬으로 자동화해 파일·문서·데이터 처리 시간을 줄이는 방법을 학습합니다.

비밀번호는 수강생에게만 제공됩니다. 입력 후 Enter 키 또는 ‘과정 열기’ 버튼을 누르세요 비밀번호는 주기적으로 갱신됩니다.
